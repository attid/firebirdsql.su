# Дорожная карта улучшения firebirdsql.su

Принятые направления — в docs/decisions/: статика в git (ADR-0001),
деплой в Docker на своём сервере (ADR-0002), Astro + Pagefind (ADR-0003),
контент первого этапа 1:1 (ADR-0004). Жёсткое ограничение — сохранение SEO.

## Этап 0 — фондация (завершён)

- [x] Репозиторий, структура, AGENTS.md, ADR
- [x] Дамп старой вики: `tools/scrape_dokuwiki.py` → `legacy/`
      (249/249 страниц, битых нет, медиафайлов нет)
- [x] git init (без коммитов — коммит только по команде владельца)

## Этап 1 — конвертация и каркас нового сайта (завершён)

- [x] Конвертер DokuWiki → Markdown (`tools/convert_dokuwiki.py`), механический, 1:1,
      с include-плагином `{{page>...}}` (инлайн сниппетов); чекер чистоты
      `tools/check_conversion.py` — 0 остатков вики-синтаксиса
- [x] Frontmatter-схема контента: заголовок, раздел, тип страницы, поля версий
      Firebird `since/until/deprecated` — пустые, но в схеме (ADR-0005)
- [x] Каркас Astro: layout, динамические страницы контента, главная, 404
- [x] Поиск Pagefind (ru, 7688 слов), подсветка SQL (Shiki dual themes),
      кнопка «копировать» у код-блоков, тёмная/светлая тема без мигания
- [x] Схема URL `/<old_id>/` (плоская, 1:1 с ID DokuWiki; id без слагификации)
      + генератор карты редиректов (`tools/make_redirect_map.py`
      → `deploy/redirects.map` + `deploy/nginx-redirects.conf`, 249 записей)
- [x] Резерв URL-пространства `/en/` под будущую локализацию (контент пока ru)
- [x] Страница `/download/` — ветки Firebird со ссылками на официальные
      бинарники (под поисковый запрос «firebird скачать»)
