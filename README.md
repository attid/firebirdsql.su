# firebirdsql.su — перенос и развитие сайта

Проект перевода сайта https://firebirdsql.su («Словарик по FireBird» —
русскоязычный справочник и FAQ по СУБД Firebird, ~215 страниц) с DokuWiki
на статический сайт, целиком живущий в git, с сохранением поискового трафика.

Принятые решения (подробности и альтернативы — в `docs/decisions/`):

- ADR-0001: статика в git, DokuWiki уходит в read-only архив;
- ADR-0002: деплой в Docker на собственном сервере (nginx + статика + карта 301);
- ADR-0003: генератор Astro, поиск Pagefind;
- ADR-0004: первый проход миграции контента 1:1, доработки — после запуска;
- ADR-0005: версионная осведомлённость контента (поля since/until/deprecated,
  фильтр «моя версия Firebird» по образцу MDN);
- ADR-0006: комментарии — remark42, авторизация Telegram + Яндекс + Google;
- ADR-0007: ИИ-ответы отложены, архитектура (RAG-готовый контент, слот в
  compose, rate limiting) резервируется сразу.

## Зачем

- Старый сайт: DokuWiki с дефолтным шаблоном, без кэша для анонимов,
  без robots.txt и sitemap.xml, canonical указывает на http://.
- Контент в git: история правок, правки от сообщества через pull request,
  полноценный бэкап, предсказуемые сборки.
- Жёсткое ограничение проекта — **сохранить SEO**: многие страницы в выдаче,
  поэтому каждый старый URL получает 301-редирект на новый.

## Структура репозитория

| Путь | Назначение |
|------|-----------|
| `legacy/` | Дамп старой вики: raw-разметка DokuWiki, `pages.json`, медиафайлы. Источник для миграции, руками не менять |
| `tools/` | Скрипты миграции: скрейпер DokuWiki, конвертер в Markdown и др. |
| `site/` | Новый статический сайт (Astro). Появляется на этапе 1 |
| `deploy/` | Конфиги nginx, карта редиректов, инструкции развёртывания |
| `docs/` | План миграции, SEO-стратегия, архитектурные решения (ADR) |

План работ — в [ROADMAP.md](ROADMAP.md). Правила работы агентов — в [AGENTS.md](AGENTS.md).
