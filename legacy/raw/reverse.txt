===== Формат =====
REVERSE( <value> )

===== Описание =====
Возвращает перевернутую строку 

===== Пример =====
<code sql>
    create index people_email on people computed by (reverse(email));
    select * from people where reverse(email) starting with reverse('.br');
</code>
