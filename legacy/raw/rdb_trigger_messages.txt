===== Формат =====
<code sql>
CREATE TABLE RDB$TRIGGER_MESSAGES (
    RDB$TRIGGER_NAME    CHAR(31) CHARACTER SET UNICODE_FSS,
    RDB$MESSAGE_NUMBER  SMALLINT,
    RDB$MESSAGE         VARCHAR(1021) CHARACTER SET NONE
);

CREATE INDEX RDB$INDEX_35 ON RDB$TRIGGER_MESSAGES (RDB$TRIGGER_NAME);
</code>

===== Описание =====
Системная таблица RDB$TRIGGER_MESSAGES хранит определения сообщений триггеров (для системного использования). 

^ Имя столбца ^ Тип ^ Описание ^
| RDB$TRIGGER_NAME  | СНАR(З1)  | Имя триггера, с которым ассоциировано сообщение.  |
| RDB$MESSAGE_NUMBER  | SMALLINT  | Номер сообщения (от 1 до 32767)  |
| RDB$MESSAGE  | VARCHAR(1021)  | Текст сообщения триггера.  |
