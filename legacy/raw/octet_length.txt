====== OCTET_LENGTH() ======

===== Доступно в =====
[[raznovidnosti_jazyka_sql|DSQL]],   [[raznovidnosti_jazyka_sql|ISQL]],   [[raznovidnosti_jazyka_sql|PSQL]]


===== Формат =====
OCTET_LENGTH(<value>)

===== Описание =====
Возвращает количество байт памяти (не путать с количеством бит, для этого сущестсвует [[BIT_LENGTH()]]), занимаемых строкой, переданной в качестве параметра <value>.

:!: Внимание ! Не во всех кодировках количество байт, занимаемых строкой, равно количеству символов !

===== Пример =====
<code sql>
SELECT RDB$RELATION_NAME, OCTET_LENGTH(RDB$RELATION_NAME), OCTET_LENGTH(TRIM(RDB$RELATION_NAME))
FROM   RDB$RELATIONS;
</code>
