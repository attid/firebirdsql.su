====== BIT_LENGTH() ======


===== Версии сервера =====

===== Доступно в =====
[[raznovidnosti_jazyka_sql|DSQL]],   [[raznovidnosti_jazyka_sql|ISQL]],   [[raznovidnosti_jazyka_sql|PSQL]]


===== Формат =====
BIT_LENGTH(<value>)

===== Описание =====
Возвращает количество бит памяти, занимаемых строкой, переданной в качестве параметра <value>.


===== Пример =====
<code sql>
select rdb$relation_name, bit_length(rdb$relation_name), bit_length(trim(rdb$relation_name))
from rdb$relations;
</code>
