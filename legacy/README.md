# legacy/ — снимок старой вики

Неизменяемый дамп DokuWiki firebirdsql.su на момент миграции.
Переснимается только скриптом `tools/scrape_dokuwiki.py`, руками не правится.

- `raw/` — raw-разметка DokuWiki (`doku.php?do=export_raw`);
- `media/` — медиафайлы, использованные в страницах;
- `pages.json` — реестр: полный список ID страниц, статус (существует/нет),
  размеры, пути к файлам, список медиа. Основа для карты редиректов и
  smoke-тестов SEO-миграции.

Дамп нужен как: (1) источник для конвертации в Markdown, (2) эталон сравнения
«до/после» при проверке 1:1-переноса, (3) список старых URL для редиректов.
