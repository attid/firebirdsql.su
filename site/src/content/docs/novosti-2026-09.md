# Новости Firebird — сентябрь 2026

## PhoenixVault: новый встраиваемый движок от IBPhoenix

13 сентября IBPhoenix анонсировала [**PhoenixVault**](https://groups.google.com/g/firebird-general/c/eZy5EroDTbo) — защищённый встраиваемый движок баз данных. Детали в анонсе скупые, но само событие заметное: IBPhoenix, исторический коммерческий партнёр Firebird, входит в нишу embedded-хранилищ. Следим за развитием.

## RDB Expert 2026.08

10 сентября вышел [**RDB Expert 2026.08**](https://groups.google.com/g/firebird-general/c/UOYmZXZWtBA) — обновление русского инструмента администрирования и разработки для Firebird. По словам авторов — стабильность и удобство работы с метаданными. Наша аудитория инструмент знает — обновляйтесь.

## РЕД База Данных 5.3.0 и 5.2.5

16 сентября РЕД СОФТ выпустила два обновления российского форка. [**5.3.0**](https://rdb.red-soft.ru/downloads/rdb50/5_3_0/) — функциональный релиз: новый CDC-коннектор на C++ с заметным ускорением, криптостойкий метод аутентификации SrpArgon2id (SRP с хэшированием Argon2id), расширенный аудит с автоматическим удалением архивных логов по истечении срока. [**5.2.5**](https://rdb.red-soft.ru/downloads/rdb50/5_2_5/) — корректирующий выпуск: исправления уязвимостей и ошибок стабильности. Тем, кто работает на пятой ветке форка, — обновиться.

## Firebird в Apache Arrow

1 сентября представлен [**adbcBridge**](https://groups.google.com/g/firebird-general/c/VybbExnGY2M) — мост из Firebird в мир колоночных данных Apache Arrow через ADBC, работающий поверх **ODBC-драйвера 3.5.0-rc1**. Для аналитики и дата-инженерии: pandas/Polars/DuckDB-экосистема теперь ближе. Заодно это повод обновить наш [раздел про ODBC](/odbc/) — свежий кандидат в релизы драйвера.

## Видео: оптимизация запросов и материализованные представления

В сентябре [официальный канал](https://www.firebirdsql.org/en/news/) выложил три записи: «Типичные ошибки оптимизации SQL-запросов» (части 1 и 2, 8–9 сентября) и «Материализованные представления в Firebird» (16 сентября). Оптимизационные разборы — маст-вотч для всех, кто пишет запросы к большим базам.

## Инструменты и экосистема

- **EmberWings 2026/3** (28 сентября) — осенний номер официального журнала Firebird Foundation: [анонс в группе](https://groups.google.com/g/firebird-general/c/3oYFHYXDbZw). Foundation выпускает журнал стабильно раз в квартал, читать бесплатно.
- [**Laravel Firebird driver v4.0.0-rc.1**](https://groups.google.com/g/firebird-general/c/IYHryqT2e3s) (28 сентября) — независимо поддерживаемое продолжение Laravel-драйвера для Firebird, автор зовёт тестировщиков. Для PHP-сообщества важная новость: драйвер получает вторую жизнь.
- [**Kuberbird 0.3.0**](https://groups.google.com/g/firebird-general/c/goDYu1cN1tU) (26 сентября) — третья версия Kubernetes-оператора за месяц (0.1.0 → 0.2.0 → 0.3.0): проект развивается быстро.
- [**FibPlus 7.9**](https://github.com/madorin/fibplus/releases/tag/v7.9.0) — первое обновление легендарной Delphi-библиотеки доступа к Firebird/InterBase за 12 лет: проект подхвачен сообществом на базе последних исходников Devrace (7.632, февраль 2014). В пакет добавлена поддержка типов и возможностей Firebird 4 и 5, сборки для Delphi 13. Для десятков тысяч Delphi-приложений на Firebird — возвращение с того света.
- [**FlameRobin 26.9.0**](https://github.com/mariuz/flamerobin/discussions/710) (4 сентября) — обновление классического открытого инструмента администрирования: ключевые слова Firebird 3+ (BOOLEAN, DECFLOAT, OFFSET и другие) корректно распознаются при подсветке и квотировании, поиск находит объекты всех типов без раскрытия дерева, переход в конец большой выборки по Ctrl+End дотягивает все записи. На чистой установке изоляция транзакций по умолчанию теперь Concurrency вместо Consistency. [Сборки](https://github.com/mariuz/flamerobin/releases/tag/v26.9.0) для всех платформ.
- [**Plamenix 1.0.0-beta**](https://groups.google.com/g/firebird-general/c/SaCoMHFHetc) (3 сентября) — Firebird Web Client, переписанный и переименованный: слой работы с базой переведён на Rust (rsfbclient), что починило MON$-таблицы и обращение с BLOB. Живой дашборд активных подключений и запросов, статистика ODS, диалекта и разрывов OIT/OAT/OST; десктоп и self-hosted веб-версия из одной кодовой базы, поддержка Firebird 2.5–5.0. Сайт — [plamenix.dev](https://plamenix.dev/), автор зовёт бета-тестировщиков на старых серверах, необычных кодировках и больших BLOB. Рядом в [официальном обзоре новых инструментов](https://firebirdsql.org/en/community-news/ides-and-tools-for-firebird) — BeeKeeper Studio.
