# INTEGER

## Версии сервера
Firebird v0.9       Firebird v1.0       Firebird v1.5       Firebird v2.0 

## Формат
```
 INTEGER;
```

## Описание
INTEGER - тип данных SQL-сервера Firebird, используемый при создании доменов, таблиц, просмотров, хранимых процедур, объявления контекстных переменных в PSQL-блоках/хранимых процедурах/триггерах.

Длинное целое число со знаком (long, longword) 

Размер: 32 бита

Диапазон/Точность: от -2 147 483 648 до 2 147 483 648
