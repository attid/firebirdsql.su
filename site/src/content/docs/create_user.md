# CREATE USER

## Версии сервера
| 2.5 | 3.0 | 4.0 | 5.0 | 6.0 |
|---|---|---|---|---|
| Да | Да | Да | Да | Да |

## Доступно в
[DSQL](/raznovidnosti_jazyka_sql/)

## Формат
```
CREATE USER username
  PASSWORD 'password'
  [FIRSTNAME 'firstname']
  [MIDDLENAME 'middlename']
  [LASTNAME 'lastname']
  [ACTIVE]
  [GRANT ADMIN ROLE]
  [USING PLUGIN pluginname]
  [TAGS (tagname = 'tagvalue' [, tagname = 'tagvalue' ...])]
```

## Описание
Оператор `CREATE USER` создаёт учётную запись пользователя Firebird. Пользователь должен отсутствовать в текущей базе данных безопасности, иначе будет выдано сообщение об ошибке.

Имя пользователя может содержать до 63 символов. Начиная с Firebird 3.0 имена подчиняются общим правилам именования идентификаторов: незаключённые в кавычки приводятся к верхнему регистру, а имена в двойных кавычках чувствительны к регистру. Таким образом, `ALEX` и `"ALEX"` — один пользователь, а `"Alex"` — уже другой.

Предложение `PASSWORD` задаёт пароль (чувствителен к регистру). Максимальная длина зависит от плагина управления пользователями (параметр `UserManager` в `firebird.conf`): для Srp эффективная длина пароля ограничена 20 байтами (ограничение хеша SHA1 — 160 бит), для Legacy_UserManager — 8 байтами.

Необязательные предложения `FIRSTNAME`, `MIDDLENAME` и `LASTNAME` задают имя, отчество и фамилию (до 32 символов каждое).

Атрибут `INACTIVE` создаёт пользователя в неактивном состоянии, при котором подключение невозможно; `ACTIVE` — в активном (по умолчанию). Доступно только при использовании Srp.

Опция `GRANT ADMIN ROLE` создаёт учётную запись с правами роли `RDB$ADMIN` в текущей базе данных безопасности: это позволяет управлять учётными записями пользователей, но не даёт специальных полномочий в обычных базах данных.

Предложение `USING PLUGIN` явно указывает плагин управления пользователями; по умолчанию берётся первый плагин из списка `UserManager`. Одноимённые пользователи, созданные разными плагинами, — разные пользователи. Предложение `TAGS` задаёт пользовательские атрибуты: имя атрибута (до 63 символов) подчиняется правилам SQL-идентификаторов, значение — до 255 символов.

## Пример
```sql
CREATE USER ivanov
  PASSWORD 'Qz7#pL92'
  FIRSTNAME 'Иван'
  LASTNAME 'Иванов'
  ACTIVE
  USING PLUGIN Srp
  GRANT ADMIN ROLE;
```
