# SEO-стратегия миграции

Жёсткое требование проекта: поисковый трафик не теряем. Ни один старый URL
после переключения не имеет права отдавать 404 или soft-404 — только 301
на новую страницу или релевантный раздел.

## Инвентаризация старых URL

Две рабочие формы старых адресов, обе отдают 200 и обе могут быть в выдаче:

- `/doku.php?id=<page_id>` — основная форма всех внутренних ссылок;
- `/<page_id>` — путь без doku.php (например `/abs`, `/sql003.summa_propisju`).

Все 249 страниц лежат в корневом пространстве имён — вложенности нет,
ID уже латиницей (транслит). Полный список даёт `legacy/pages.json`
(снимок `tools/scrape_dokuwiki.py`). Проиндексированные, но уже мёртвые
страницы (пример: `glossarij:coalesce` из кэша поиска) фиксируем отдельно
и уводим редиректом на релевантный раздел, а не в 404.

## Новая схема URL

`/<slug>/` — плоская, честное 1:1 с ID страницы DokuWiki:
`abs` → `/abs/`, `sql003.summa_propisju` → `/sql003.summa_propisju/`.
Легко генерировать карту автоматически; структуру разделов строит
навигация сайта, а не URL.

## Карта редиректов

Генератор `tools/make_redirect_map.py` из `legacy/pages.json` строит:

1. `deploy/redirects.map` — nginx map `$arg_id` → новый путь (для `/doku.php`);
2. правило для path-формы `/<page_id>` (регулярка + тот же map).

Обновляется только регенерацией, руками не редактируется. Изменение URL
страницы = новая запись в карте, иначе запрещено (см. AGENTS.md).

## Инфраструктура нового сайта

- `sitemap.xml` — все новые страницы (у старого сайта сид карта нет вообще);
- `robots.txt` — закрыть служебное, указать sitemap (старый отдаёт soft-404);
- canonical — только `https://` (старый отдаёт canonical на http://);
- честные 404 без индексации; мета-описания и OG-теги на каждую страницу;
- разметка schema.org: `DefinedTerm` для терминов глоссария, `TechArticle`
  для статей.

## Контроль и проверка

До переключения:

- зафиксировать базовые метрики: Яндекс.Метрика 25113035, GSC, Я.Вебмастер
  (позиции/клики по страницам, список проиндексированных URL);
- smoke-тест на стенде: по всему `pages.json` каждый старый URL (обе формы)
  → 301 → 200.

После переключения:

- тот же smoke-тест на проде;
- мониторинг 404 в GSC/Я.Вебмастере, запрос на переобход sitemap;
- сравнение трафика до/после по неделям; всплеск 404 = откат upstream на
  старый контейнер вики и разбор.

## Откат

Старый контейнер DokuWiki остаётся работать на сервере. Переключение —
смена upstream; откат в обратную сторону занимает минуты и не теряет данных.
