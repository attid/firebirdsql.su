# Анализ поискового спроса: Яндекс.Вордстат, «firebird»

Источник: docs/metrics-baseline/wordstat_top_queries.csv (локально, в git не входит),
топ частотных запросов по слову «firebird», 22.08–22.09.2026, все регионы.
Из 1049 запросов после отсечения нерелевантных (Pontiac, Adidas, Ganzo, печи,
гитары, кино) остаются ~580 связанных с СУБД. Ниже — агрегированная выжимка
для планирования контента (этап 4).

## Выводы для контент-плана (этап 4)

1. **Версии — главный спрос** (~2500/мес): переключатель «моя версия»
   (ADR-0005) и контент под 2.5/3.0/5.x — приоритет №1.
2. **/download/ в центре спроса** (~1000/мес): добавить разделы по версиям
   с прямыми ссылками на официальные архивы.
3. **Посадочная «Что такое Firebird»** — 401 запрос «что это за программа»:
   вводная страница под прямой ответ.
4. **Новые страницы под явный спрос**: ODBC-драйвер (216), установка на
   Windows (160+118), порты/сетевые настройки (143). Плюс 160 недостающих
   страниц из convert_report.json (trigger, udf, blob…) — там спрос доказан
   ещё и внутренними ссылками вики.
5. Хвост ошибок (gdscodes) — постраничный каталог под длинный хвост
   запросов вида «firebird ошибка -902».
