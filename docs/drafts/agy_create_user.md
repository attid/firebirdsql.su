# CREATE USER

## Доступно в
DSQL

## Формат
```sql
CREATE USER username
  PASSWORD 'password'
  [<user_option> [<user_option> ...]]
  [TAGS ( <tag> [, <tag>  ...] )]

<user_option> ::=
    FIRSTNAME 'firstname'
  | MIDDLENAME 'middlename'
  | LASTNAME 'lastname'
  | {ACTIVE | INACTIVE}
  | USING PLUGIN pluginname
  | GRANT ADMIN ROLE

<tag> ::=
  tagname = 'string_value'
```

## Описание
Оператор `CREATE USER` предназначен для создания новой учётной записи пользователя в базе данных безопасности Firebird. Пользователь с указанным именем должен отсутствовать в текущей базе безопасности, иначе возвращается ошибка. Имена пользователей подчиняются общим правилам SQL-идентификаторов (имя в кавычках чувствительно к регистру).

Обязательное предложение `PASSWORD` задаёт пароль, чувствительный к регистру. Максимальная или эффективная длина пароля определяется используемым плагином: для `Srp` эффективная длина составляет 20 байт (из-за длины хеша SHA1), а для `Legacy_UserManager` максимальная длина равна 8 байтам.

Ключевые опции оператора:
- `FIRSTNAME`, `MIDDLENAME`, `LASTNAME` — задают имя, отчество и фамилию (до 32 символов).
- `ACTIVE` / `INACTIVE` — определяют активность учётной записи (неактивный пользователь не может подключиться). По умолчанию `ACTIVE` (доступно для плагина `Srp`).
- `GRANT ADMIN ROLE` — предоставляет права роли `RDB$ADMIN` в базе данных безопасности для администрирования пользователей, не давая привилегий в обычных базах данных.
- `USING PLUGIN` — указывает плагин управления пользователями (по умолчанию используется первый из параметра `UserManager`). Одноимённые пользователи в разных плагинах считаются разными.
- `TAGS` — задаёт пользовательские атрибуты в формате ключ-значение (имя тега до 63 символов, значение до 255 символов).

## Пример
```sql
CREATE USER ivan
  PASSWORD 'SecretPass123'
  FIRSTNAME 'Иван'
  LASTNAME 'Иванов'
  ACTIVE
  USING PLUGIN Srp
  GRANT ADMIN ROLE
  TAGS (department = 'IT', office = '305');
```
