# BASE64_DECODE

## Доступно в
DSQL, PSQL

## Формат
```sql
BASE64_DECODE (base64_data)
```

## Описание
Функция `BASE64_DECODE` декодирует строку с данными, закодированными алгоритмом Base64, и возвращает полученное значение как `VARBINARY` или `BLOB` в зависимости от типа переданного входного аргумента.

Параметр `base64_data` принимает данные в кодировке Base64, дополненные символом `=` до длины, кратной 4. Возвращаемый тип данных — `BLOB` или `VARBINARY`.

Правила валидации длины и вычисления типа результата:
* Если длина типа данных аргумента `base64_data` не кратна 4, ошибка возникает на этапе подготовки запроса (prepare time).
* Если длина фактического значения `base64_data` не кратна 4, ошибка генерируется на этапе выполнения запроса (execution time).
* В случаях, когда входной аргумент не является `BLOB`, длина результирующего типа вычисляется по формуле `type_length * 3 / 4`, где `type_length` — максимальная длина в байтах типа входного аргумента.

## Пример
```sql
SELECT CAST(BASE64_DECODE('VGVzdCBiYXNlNjQ=') AS VARCHAR(12)) AS decoded_str
FROM rdb$database;

/*
Результат:
DECODED_STR
============
Test base64
*/
```
