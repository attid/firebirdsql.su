• # BASE64_ENCODE

  ## Доступно в

  DSQL, PSQL

  ## Формат

  ```
  BASE64_ENCODE (binary_data)
  ```

  | Параметр | Описание |
  |---|---|
  | binary_data | Двоичные данные для кодирования |

  ## Описание

  Функция `BASE64_ENCODE` кодирует двоичные данные _binary_data_ по алгоритму base64 и возвращает результат в текстовом виде. Тип результата зависит от типа входного аргумента: для не-BLOB аргументов возвращается `VARCHAR CHARACTER SET ASCII`, для BLOB — `BLOB SUB_TYPE TEXT CHARACTER SET ASCII`. Набор символов ASCII гарантирует, что закодированная строка состоит только из переносимых символов, безопасных для хранения и передачи в текстовых протоколах.

  Возвращаемое значение при необходимости дополняется знаками `=`, чтобы его длина была кратна четырём, как того требует стандарт base64.

  Когда входной аргумент не является `BLOB`, длина результирующего типа вычисляется по формуле `type_length * 4 / 3` с округлением в большую сторону до числа, кратного четырём, где _type_length_ — максимальная длина входного типа в байтах. Это соответствует накладным расходам base64: каждые 3 байта исходных данных превращаются в 4 символа.

  Типичные применения — передача двоичных данных (хешей, изображений, сериализованных структур) через текстовые каналы: JSON, XML, электронную почту, HTTP-заголовки. Обратное преобразование выполняет функция `BASE64_DECODE`, аналогичное кодирование в шестнадцатеричном виде — `HEX_ENCODE`.

  ## Пример

  ```sql
  select base64_encode('Test base64')
  from rdb$database;
  ```

  ```
  BASE64_ENCODE
  ================
  VGVzdCBiYXNlNjQ=
  ```

  ```sql
  -- Кодирование хеша для включения в текстовый отчёт
  select base64_encode(hash_value) as hash_b64
  from file_hashes
  where file_id = 42;
  ```
