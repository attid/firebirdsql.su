# ODBC-драйвер для Firebird

ODBC-драйвер для Firebird — это стандартный программный интерфейс, который позволяет сторонним приложениям работать с базами данных Firebird через универсальный протокол Open Database Connectivity.

Если вам требуется подключить к существующей базе данных Firebird такие инструменты, как Microsoft Excel, Power BI, системы сквозной аналитики, интеграционные шлюзы 1С или скрипты на Python (`pyodbc`), этот драйвер — стандартный и наиболее прямой путь.

---

## Откуда скачать

Официальный компонент распространяется под названием **Firebird ODBC/JDBC Driver**. 

Драйвер загружается исключительно с официального сайта проекта:
* Сайт: **firebirdsql.org**
* Раздел: **ODBC/JDBC driver**

Драйвер полностью совместим и поддерживает версии серверов **Firebird от 2.5 до 5.x**.

## Установка и настройка: Windows и Linux

### Установка на Windows

На платформе Windows драйвер поставляется в виде отдельного инсталлятора. 

> **Критическое правило разрядности (32 vs 64 bit):**  
> Разрядность устанавливаемого драйвера обязана строго совпадать с **разрядностью клиентского приложения**, а не с разрядностью самого сервера Firebird или операционной системы. 
> 
> * Пример: если у вас 64-битная Windows и 64-битный сервер Firebird, но используется 32-битный Excel / Python / 1С-клиент — вам **обязательно** нужно ставить **32-битный ODBC-драйвер**. Для 64-битного софта ставится 64-битный драйвер. При необходимости можно установить обе версии параллельно.

### Настройка DSN в Windows

Для создания системного или пользовательского источника данных (DSN) используется утилита `odbcad32.exe`. Из-за специфики путей в Windows важно открывать корректную версию:

* **Для 64-битных приложений и драйверов:** `C:\Windows\System32\odbcad32.exe`
* **Для 32-битных приложений и драйверов:** `C:\Windows\SysWOW64\odbcad32.exe`

### Установка на Linux

В Linux-окружении драйвер работает в связке с менеджером драйверов **unixODBC**. Развертывание сводится к установке библиотек драйвера и регистрации модуля в конфигурационном файле `/etc/odbcinst.ini`.

## Строка подключения (Connection String)

При прямом подключении без предварительного создания DSN (DSN-less) используется стандартный формат строки подключения.

**Пример рабочей строки подключения:**

```text
DRIVER={Firebird ODBC Driver};DATABASE=localhost/3050:C:\data\base.fdb;UID=SYSDBA;PWD=пароль;CHARSET=UTF8;
```

* **DRIVER** — системное имя зарегистрированного драйвера (`{Firebird ODBC Driver}`).
* **DATABASE** — путь к базе данных в формате `хост/порт:путь_к_файлу.fdb` (или алиас).
* **UID / PWD** — учетные данные пользователя СУБД.
* **CHARSET** — кодировка сессии (критично для корректной передачи строк).

## Типичные проблемы и грабли

| Проблема | Причина | Решение |
| :--- | :--- | :--- |
| **«Архитектура драйвера не соответствует архитектуре приложения» ([IM014])** | Несовпадение разрядности приложения и ODBC-драйвера. Самый частый источник ошибок. | Проверьте битность программы (32 или 64 бит) и установите ODBC-драйвер соответствующей разрядности. |
| **Крякозябры или знаки вопроса вместо кириллицы** | Не задана или некорректно указана кодировка подключения. | Явно укажите параметр `CHARSET=UTF8;` (или `CHARSET=WIN1251;` в зависимости от кодировки вашей БД) в строке подключения или свойствах DSN. |
| **Ошибка аутентификации / протокола при подключении к новому серверу** | Использование устаревшей версии ODBC-драйвера с современными серверами (Firebird 4.x / 5.x). | Обновите драйвер с firebirdsql.org до актуальной версии, поддерживающей современные плагины аутентификации и протоколы wire-level. |
| **DSN не отображается в списке источников приложения** | DSN настроен через утилиту `odbcad32.exe` другой разрядности. | Запустите правильный `odbcad32.exe`: из `System32` для 64-бит или из `SysWOW64` для 32-бит. |

## Чем еще подключаться к Firebird

Если вам не требуется универсальный слой ODBC, для администрирования, написания запросов и прямой разработки используются специализированные инструменты:

* **isql** — штатная консольная утилита Firebird для выполнения скриптов и запросов.
* **IBExpert** — мощная специализированная IDE для администрирования и разработки под Firebird/InterBase.
* **DBeaver** — универсальный графический менеджер баз данных (работает через JDBC).
