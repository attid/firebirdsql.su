# ROLLBACK

## Доступно в
DSQL, ESQL

## Формат
```sql
ROLLBACK [WORK] [TRANSACTION tr_name]
  [RETAIN [SNAPSHOT] | TO SAVEPOINT sp_name] [RELEASE];
```

## Описание
Оператор `ROLLBACK` отменяет все изменения данных (вставку, обновление, удаление), выполненные в контексте транзакции, и никогда не приводит к возникновению ошибок. Если не указано предложение `RETAIN`, оператор полностью завершает транзакцию и освобождает все связанные с ней ресурсы сервера.

Необязательное ключевое слово `WORK` поддерживается для совместимости с другими СУБД. Предложение `TRANSACTION` задаёт имя транзакции (доступно только в Embedded SQL); при его отсутствии откат применяется к транзакции по умолчанию.

Предложение `RETAIN` отменяет изменения данных, но оставляет транзакцию активной, сохраняя её идентификатор, контекст, открытые курсоры и ресурсы сервера. При этом для уровней изоляции `SNAPSHOT` и `SNAPSHOT TABLE STABILITY` снимок состояния базы сохраняется с момента старта транзакции, а для `READ COMMITTED` — обновляется на момент выполнения отката.

Предложение `TO SAVEPOINT` (доступно в DSQL) выполняет откат изменений до указанной точки сохранения. При этом отменяются только модификации данных, произведённые после создания точки, освобождаются соответствующие блокировки строк, а более поздние точки сохранения удаляются. Значения пользовательского контекста, установленные через `RDB$SET_CONTEXT()`, не сбрасываются.

## Пример
```sql
-- Полный откат транзакции и освобождение серверных ресурсов
DELETE FROM CUSTOMER WHERE ID = 42;
ROLLBACK;

-- Частичный откат изменений к созданной точке сохранения
SAVEPOINT SP_BEFORE_UPDATE;
UPDATE ACCOUNT SET BALANCE = BALANCE - 500 WHERE ACC_ID = 10;
ROLLBACK TO SAVEPOINT SP_BEFORE_UPDATE;
```
