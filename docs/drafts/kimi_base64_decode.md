• # BASE64_DECODE

  ## Доступно в

  DSQL, PSQL

  ## Формат

  ```
  BASE64_DECODE (base64_data)
  ```

  ## Описание

  `BASE64_DECODE` декодирует строку с данными, закодированными алгоритмом Base64, и возвращает декодированное значение как `VARBINARY` или `BLOB` — в зависимости от типа входного аргумента.

  Параметр `base64_data` — данные в кодировке Base64, дополненные знаком `=` до длины, кратной 4. Функция требует корректного выравнивания входных данных:

  - если длина типа `base64_data` не кратна 4, ошибка возникает во время подготовки запроса;
  - если длина значения `base64_data` не кратна 4, ошибка возникает во время выполнения.

  Тип возвращаемого результата — `BLOB` или `VARBINARY`. Когда входной аргумент не является `BLOB`, длина результирующего типа вычисляется как `type_length * 3/4`, где `type_length` — максимальная длина в байтах типа входного аргумента.

  ## Пример

  ```sql
  select cast(base64_decode('VGVzdCBiYXNlNjQ=') as varchar(12))
  from rdb$database;
  ```
