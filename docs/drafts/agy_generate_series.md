# GENERATE SERIES

## Доступно в
DSQL, PSQL

## Формат
```sql
<generate_series_function> ::=
    GENERATE_SERIES(<start>, <finish> [, <step>]) [AS] <correlation name> [ ( <derived column name> ) ]
```

## Описание
Функция `GENERATE_SERIES` создаёт набор данных (табличный ряд чисел) в заданном интервале. Значения аргументов `start` (начало), `finish` (конец) и необязательного `step` (шаг, по умолчанию равен 1) могут быть переменными, литералами или скалярными выражениями числовых типов `SMALLINT`, `INTEGER`, `BIGINT`, `INT128` или `NUMERIC/DECIMAL`.

Параметр `step` может быть положительным или отрицательным, но не может быть равен нулю (в противном случае возвращается ошибка). Генерация последовательности завершается, когда очередное вычисленное значение выходит за пределы `finish`. Если направление шага не соответствует границам диапазона (`start < finish` при `step < 0` или `start > finish` при `step > 0`), функция возвращает пустой набор.

Возвращаемый набор содержит один столбец типа `BIGINT`, `INT128` или `NUMERIC(18, x)/NUMERIC(38, x)`, где масштаб (`SCALE`) равен максимальному масштабу из переданных аргументов. Прямое обращение по имени `SELECT GENERATE_SERIES FROM ...` без явного алиаса столбца запрещено и вызовет ошибку, поэтому рекомендуется всегда задавать псевдоним таблицы и столбца (например, `AS S(n)`).

Функция является новой и доступна начиная с Firebird 6.0 (версия находится в активной разработке).

## Пример
```sql
-- Генерация интервалов времени с шагом в одну минуту
SELECT
  DATEADD(n MINUTE TO TIMESTAMP '2025-01-01 12:00') AS START_TIME,
  DATEADD(n MINUTE TO TIMESTAMP '2025-01-01 12:00:59.9999') AS FINISH_TIME
FROM GENERATE_SERIES(0, 59) AS S(n);

-- Генерация дробных значений с шагом 0.1
SELECT n
FROM GENERATE_SERIES(0, 9.9, 0.1) AS S(n);
```
