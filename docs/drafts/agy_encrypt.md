# ENCRYPT

## Доступно в
DSQL, PSQL

## Формат
```sql
ENCRYPT (_input_
  [USING <algorithm>] [MODE <mode>]
  KEY _key_
  [IV _iv_] [<ctr_type>] [CTR_LENGTH _ctr_length_]
  [COUNTER _initial_counter_] )

<algorithm> ::= <block_cipher> | <stream_cipher>

<block_cipher> ::=
    AES | ANUBIS | BLOWFISH | KHAZAD | RC5
  | RC6 | SAFER+ | TWOFISH | XTEA

<stream_cipher> ::= CHACHA20 | RC4 | SOBER128

<mode> ::= CBC | CFB | CTR | ECB | OFB

<ctr_type> ::= CTR_BIG_ENDIAN | CTR_LITTLE_ENDIAN
```

## Описание
Функция `ENCRYPT` выполняет шифрование данных с использованием симметричного шифра. В качестве входного параметра `_input_` принимает строку или `BLOB`. Возвращает `BLOB SUB_TYPE BINARY`, если на вход передан `BLOB`, либо `VARBINARY` для всех остальных текстовых и двоичных типов данных.

Поддерживаются блочные и потоковые алгоритмы шифрования:
* Параметр `MODE` определяет режим и обязателен для блочных шифров. Для режимов `ECB` и `CBC` размер входных данных должен быть кратен размеру блока (при необходимости данные дополняются пробелами или нулями вручную).
* Вектор инициализации `IV` обязателен для всех блочных шифров (за исключением `ECB`) и потоковых алгоритмов (за исключением `RC4`). Как правило, его длина должна соответствовать размеру блока алгоритма.
* В режиме `CTR` можно дополнительно настроить порядок байтов счётчика `ctr_type` (по умолчанию `CTR_LITTLE_ENDIAN`) и длину счётчика `CTR_LENGTH` (по умолчанию равна длине `IV`).
* Для алгоритма `CHACHA20` доступен параметр начального значения счётчика `COUNTER` (по умолчанию равен 0).

Размеры передаваемых ключа `_key_` и вектора инициализации `_iv_` должны строго соответствовать требованиям выбранного алгоритма.

## Пример
```sql
SELECT ENCRYPT('897897' USING SOBER128 KEY 'AbcdAbcdAbcdAbcd' IV '01234567')
FROM RDB$DATABASE;
```
