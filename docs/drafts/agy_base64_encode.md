# BASE64_ENCODE

## Доступно в
DSQL, PSQL

## Формат
```sql
BASE64_ENCODE (binary_data)
```

## Описание
Функция `BASE64_ENCODE` выполняет кодирование входных двоичных данных (*binary_data*) с помощью алгоритма Base64 и возвращает результат в виде символьной строки в кодировке `ASCII`.

Параметры функции:
* `binary_data` — двоичные данные для кодирования.

Тип возвращаемого значения зависит от типа входного аргумента:
* `VARCHAR CHARACTER SET ASCII` — если на вход переданы данные любого типа, отличного от `BLOB`;
* `BLOB SUB_TYPE TEXT CHARACTER SET ASCII` — если входной аргумент имеет тип `BLOB`.

Возвращаемое значение дополняется знаком `=`, чтобы итоговая длина строки была кратна 4.

Если входной аргумент не является `BLOB`, размер результирующего строкового типа вычисляется по формуле `type_length * 4 / 3` с округлением в большую сторону до ближайшего числа, кратного четырём, где *type_length* — максимальная длина входного типа данных в байтах.

## Пример
```sql
SELECT BASE64_ENCODE('Test base64')
FROM RDB$DATABASE;

/*
BASE64_ENCODE
================
VGVzdCBiYXNlNjQ=
*/
```
