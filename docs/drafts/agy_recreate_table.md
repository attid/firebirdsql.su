# RECREATE TABLE

## Доступно в
DSQL.

## Формат
```sql
RECREATE [GLOBAL TEMPORARY] TABLE tablename
  [EXTERNAL [FILE] 'filespec']
  (<col_def> [, <col_def> | <tconstraint> ...])
  [ON COMMIT {DELETE | PRESERVE} ROWS]
  [SQL SECURITY {DEFINER | INVOKER}]
```

## Описание
Оператор `RECREATE TABLE` предназначен для создания новой таблицы или полного пересоздания уже существующей в базе данных. Логически он совмещает выполнение команд `DROP TABLE` и `CREATE TABLE` в рамках единой DDL-операции.

Если таблица с указанным именем отсутствует, оператор просто создаёт её. Если же таблица уже существует, `RECREATE TABLE` пытается удалить старую таблицу вместе со всеми хранящимися в ней данными, после чего формирует новую структуру с заданными параметрами с нуля.

Ключевые особенности и ограничения:
- **Зависимости:** выполнение оператора завершится ошибкой, если пересоздаваемая таблица имеет зависимости в базе данных (на неё ссылаются внешние ключи, представления, хранимые процедуры, функции или триггеры). В таких случаях предварительно требуется удалить или изменить зависимые объекты.
- **Ключевые предложения:** поддерживается создание стандартных, глобальных временных (`GLOBAL TEMPORARY`) и внешних (`EXTERNAL [FILE]`) таблиц, управление хранением строк транзакции (`ON COMMIT`), а также указание контекста безопасности (`SQL SECURITY`).

**Отличие от `ALTER TABLE`:**  
В отличие от оператора `ALTER TABLE`, который модифицирует структуру таблицы с сохранением накопленных данных и существующих зависимостей, `RECREATE TABLE` полностью уничтожает прежний объект и очищает все данные. Это делает оператор удобным решением для идемпотентных скриптов развертывания, инициализации схемы и тестовых сред.

## Пример
```sql
RECREATE TABLE order_items (
    item_id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    order_id BIGINT NOT NULL,
    product_name VARCHAR(100) NOT NULL,
    quantity NUMERIC(12, 3) DEFAULT 1 NOT NULL,
    unit_price NUMERIC(15, 2) NOT NULL,
    discount NUMERIC(5, 2) DEFAULT 0.00,
    CONSTRAINT chk_order_items_qty CHECK (quantity > 0)
);
```
