# Подключение к Firebird из Python

Быстрый старт по синхронной работе с СУБД Firebird из Python-приложений: выбор драйвера, установка, базовый скрипт, подводные камни с DSN и параметризованные запросы.

---

### Выбор драйвера: почему pure-python?

В экосистеме Python доступно несколько библиотек для работы с Firebird, но для базовых задач и микросервисов стандартом де-факто стал пакет **`firebirdsql`**.

Его главное преимущество — **чистый Python (pure Python)**. Библиотека реализует сетевой wire-протокол Firebird напрямую и не требует наличия в системе скомпилированной клиентской библиотеки `fbclient.so` или `fbclient.dll`. Благодаря этому `firebirdsql` идеально подходит для развёртывания в Docker-контейнерах и легковесных виртуальных окружениях (venv): никаких системных зависимостей, сборок и танцев с путями библиотек.

---

### Установка

Установите стабильную версию драйвера через `pip`:

```bash
pip install firebirdsql==1.4.7
```

### Базовое подключение и выборка данных

Драйвер строго следует стандарту DB-API 2.0 (PEP 249). Ниже приведён минимальный рабочий пример подключения к тестовой базе данных `employee.fdb` и чтения записей:

```python
import firebirdsql

con = firebirdsql.connect(
    dsn="firebird:/var/lib/firebird/data/employee.fdb",
    user="SYSDBA",
    password="masterkey",
    charset="utf-8",
)
cur = con.cursor()
cur.execute("SELECT FIRST_NAME, LAST_NAME, SALARY FROM EMPLOYEE ORDER BY SALARY DESC ROWS 5")
for first, last, salary in cur.fetchall():
    print(f"  {first} {last} — {salary:.2f}")
con.close()
```

> **Кодировка:** параметр `charset="utf-8"` обязателен при работе с кириллицей, чтобы избежать ошибок декодирования строк при чтении и записи.

### Важный нюанс: формат DSN и указание порта

> [!WARNING] Ошибка «unavailable database» в Firebird 5
> Стандартный синтаксис DSN в протоколе Firebird поддерживает указание порта в виде `host/port:path` (или `host:port:path`). Однако в связке **Firebird 5** и **`firebirdsql==1.4.7`** явное указание порта (например, `dsn="firebird/3050:/var/lib/..."`) приводит к сбою подключения с ошибкой `unavailable database`.
> 
> **Решение:** если сервер слушает стандартный порт `3050`, просто опускайте его в DSN:
> ```python
> dsn = "firebird:/var/lib/firebird/data/employee.fdb"
> ```
> Драйвер автоматически обратится к порту `3050` по умолчанию.

### Безопасное выполнение: параметризованные запросы

Никогда не склеивайте SQL-строки через f-строки или оператор `%`, чтобы не создавать уязвимости для SQL-инъекций. В соответствии с DB-API 2.0 в `firebirdsql` используется позиционный плейсхолдер `?`, а параметры передаются вторым аргументом в виде кортежа или списка:

```python
dept = "Sales"
cur.execute("SELECT FIRST_NAME, LAST_NAME FROM EMPLOYEE WHERE DEPT = ?", (dept,))
rows = cur.fetchall()
```

### Альтернативные драйверы

Если вашему проекту требуются специфические возможности клиентской библиотеки:

* **`firebird-driver`** — современный официальный драйвер от команды Firebird. Предоставляет расширенный функционал новых версий СУБД, но требует установленной библиотеки `fbclient`.
* **`fdb`** — классическая устаревшая библиотека (legacy). Также требует наличие нативной `fbclient` и не рекомендуется для новых проектов.
