# RECREATE VIEW

## Доступно в
DSQL

## Формат
```sql
RECREATE VIEW viewname [<full_column_list>]
AS <select_statement>
[WITH CHECK OPTION];

<full_column_list> ::= (colname [, colname ...])
```

## Описание
Оператор `RECREATE VIEW` предназначен для создания нового или полного пересоздания существующего представления в базе данных. Логически операция `RECREATE` эквивалентна последовательному выполнению операторов `DROP VIEW` и `CREATE VIEW`, объединённых в одну команду.

Если представление с заданным именем отсутствует в схеме, оператор создаёт его. Если объект уже существует, Firebird сначала пытается удалить старое представление, а затем создаёт новое с указанным определением.

Параметры и ключевые элементы оператора:
- `viewname` — имя представления, содержащее до 63 символов.
- `<full_column_list>` — необязательный список явных имён столбцов (`colname`). Дублирование имён столбцов не допускается.
- `<select_statement>` — оператор выборки `SELECT`, формирующий результирующий набор данных представления.
- `WITH CHECK OPTION` — опциональное предложение, проверяющее соответствие условий предложения `WHERE` при операциях вставки и обновления данных через представление.

**Отличия от CREATE VIEW и ALTER VIEW:**
- `CREATE VIEW` завершается ошибкой, если представление с таким именем уже существует.
- `ALTER VIEW` изменяет текст запроса существующего представления без его удаления, сохраняя метаданные и назначенные привилегии пользователей.
- `RECREATE VIEW` удаляет старый объект и формирует его заново, поэтому все ранее выданные права доступа (GRANT) сбрасываются.

**Ограничение по зависимостям:**
Поскольку оператор выполняет удаление перед созданием, `RECREATE VIEW` не выполнится и завершится ошибкой, если существующее представление имеет зависимости (на него ссылаются другие представления, триггеры или хранимые процедуры).

## Пример
```sql
RECREATE VIEW V_ACTIVE_CUSTOMERS (CUSTOMER_ID, CUSTOMER_NAME, CITY, TOTAL_ORDERS)
AS
SELECT 
    C.ID,
    C.NAME,
    C.CITY,
    COUNT(O.ID)
FROM CUSTOMER C
LEFT JOIN ORDERS O ON O.CUSTOMER_ID = C.ID
WHERE C.IS_ACTIVE = 1
GROUP BY C.ID, C.NAME, C.CITY
WITH CHECK OPTION;
```
