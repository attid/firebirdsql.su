# CRYPT_HASH

## Доступно в
DSQL, PSQL

## Формат
```
CRYPT_HASH (_value_ USING <algorithm>)

<algorithm> ::= { MD5 | SHA1 | SHA256 | SHA512 | SHA3_224 | SHA3_256 | SHA3_384 | SHA3_512 }
```

## Описание
Функция `CRYPT_HASH` возвращает криптографический хэш входной строки, вычисленный с использованием указанного алгоритма. Возвращаемый результат имеет тип данных `VARBINARY`.

Функция принимает следующие параметры:
* **value** — выражение любого типа данных. Если переданное значение имеет не строковый и не бинарный тип, оно автоматически приводится к строковому представлению. Функция полностью поддерживает текстовые `BLOB` любой длины и с любым набором символов.
* **algorithm** — алгоритм хеширования, указываемый в предложении `USING`. Допустимые значения: `MD5`, `SHA1`, `SHA256`, `SHA512`, `SHA3_224`, `SHA3_256`, `SHA3_384` и `SHA3_512`.

Использование алгоритмов `MD5` и `SHA1` не рекомендуется из-за известных серьезных проблем с безопасностью (уязвимости коллизий). Они поддерживаются и предоставляются только для обеспечения обратной совместимости.

## Пример
```sql
SELECT CRYPT_HASH(x USING SHA256) FROM MyTable;
-- результат типа VARBINARY
```
