# CLOSE

## Доступно в
PSQL

## Формат
```sql
CLOSE cursor_name;
```

## Описание
Оператор `CLOSE` предназначен для явного закрытия ранее открытого именованного курсора в процедурном языке (PSQL).

В качестве единственного обязательного параметра оператор принимает `cursor_name` — имя открытого курсора. Данный курсор должен быть предварительно объявлен в блоке объявлений текущего модуля с использованием оператора `DECLARE ... CURSOR`. Оператор `CLOSE` применим исключительно к курсорам, созданным через `DECLARE ... CURSOR`.

После выполнения оператора курсор переходит в закрытое состояние, а связанные с ним структуры освобождаются. Если открытый курсор не был закрыт явно с помощью оператора `CLOSE`, сервер Firebird закроет его автоматически по завершении выполнения кода триггера, хранимой процедуры, хранимой функции или анонимного PSQL-блока (`EXECUTE BLOCK`), в рамках которого курсор был открыт.

## Пример
```sql
EXECUTE BLOCK
RETURNS (
    EMP_NO SMALLINT,
    FULL_NAME VARCHAR(37)
)
AS
  DECLARE C CURSOR FOR (
    SELECT EMP_NO, FULL_NAME 
    FROM EMPLOYEE 
    WHERE DEPT_NO = '600'
  );
BEGIN
  OPEN C;
  WHILE (1 = 1) DO
  BEGIN
    FETCH C INTO :EMP_NO, :FULL_NAME;
    IF (ROW_COUNT = 0) THEN
      LEAVE;
    SUSPEND;
  END
  CLOSE C;
END
```
