# LAST_DAY

## Доступно в
DSQL, PSQL

## Формат
```
LAST_DAY(OF <period> FROM date_or_timestamp)

<period> ::= YEAR | QUARTER | MONTH | WEEK
```

## Описание
Функция `LAST_DAY` возвращает дату или метку времени, соответствующую последнему дню заданного периода (`YEAR`, `QUARTER`, `MONTH` или `WEEK`) для переданного значения даты или времени.

В качестве аргумента `date_or_timestamp` функция принимает выражение типа `DATE` или `TIMESTAMP [WITH | WITHOUT] TIME ZONE`. Тип возвращаемого результата полностью соответствует типу переданного аргумента (`DATE` или соответствующий `TIMESTAMP`).

Особенности работы:
- При передаче аргумента типа `TIMESTAMP` возвращаемое значение сохраняет исходную временную часть без изменений.
- При расчете периода `WEEK` последним днем недели считается суббота, что согласуется с логикой работы функции `EXTRACT` при извлечении части `WEEKDAY`.

Функция предназначена для упрощения вычисления границ календарных интервалов (конец недели, месяца, квартала или года) в запросах DSQL и процедурном коде PSQL.

## Пример
```sql
-- Получение последнего дня текущего месяца
SELECT LAST_DAY(OF MONTH FROM CURRENT_DATE) FROM RDB$DATABASE;

-- Получение последнего дня года для временной метки с сохранением времени
SELECT LAST_DAY(OF YEAR FROM CURRENT_TIMESTAMP) FROM RDB$DATABASE;
```
