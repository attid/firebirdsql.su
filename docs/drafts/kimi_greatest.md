• # GREATEST

  ## Доступно в

  DSQL, PSQL

  ## Формат

  ```
  GREATEST( <value> [, <value> ...] )

  MAXVALUE ( <value> [, <value> ...] )
  ```

  ## Описание

  Функция `GREATEST` возвращает максимальное значение из списка входных аргументов `<value>`. Аргументами могут быть выражения любых совместимых типов: числа, строки, а также значения типов `DATE`, `TIME` и `TIMESTAMP`. Тип возвращаемого результата совпадает с типом первого аргумента функции. Список должен содержать как минимум один аргумент; на практике функция полезна при сравнении двух и более выражений — например, при выборе наибольшей цены из нескольких колонок или при установке нижней границы значения.

  Следует учитывать особенность обработки `NULL`: если один или более входных аргументов имеют значение `NULL`, то результатом функции `GREATEST` также будет `NULL`. В этом она отличается от агрегатной функции `MAX`, которая игнорирует `NULL`-значения. Если такое поведение нежелательно, аргументы следует предварительно обработать, например, с помощью `COALESCE`.

  Функции `GREATEST` и `MAXVALUE` являются синонимами. `GREATEST` — совместимый с SQL-стандартом псевдоним функции `MAXVALUE`, которая была доступна до Firebird 6.0. Функция появилась в Firebird 6.0 — версии, находящейся в разработке (доступны снапшоты).

  ## Пример

  ```sql
  SELECT GREATEST(PRICE_1, PRICE_2, 10) AS PRICE
  FROM PRICELIST
  ```

  ```sql
  SELECT MAXVALUE(PRICE_1, PRICE_2) AS PRICE
  FROM PRICELIST
  ```

  Первый запрос возвращает для каждой строки прайс-листа наибольшую из двух цен, но не ниже 10; второй — то же самое через синоним `MAXVALUE`, без нижней границы.
