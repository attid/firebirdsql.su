# BLOB_APPEND

## Доступно в
DSQL, PSQL

## Формат
```sql
BLOB_APPEND(<blob> [, <value1>, ... <valueN>])
```

## Описание
Функция предназначена для эффективной конкатенации BLOB без создания промежуточных временных объектов. В отличие от оператора конкатенации `||`, последовательные вызовы `blob = BLOB_APPEND(blob, ...)` не порождают множество временных BLOB, что существенно экономит оперативную память, снижает дисковый ввод-вывод и предотвращает разрастание файла базы данных.

Функция возвращает временный незакрытый BLOB с флагом `BLB_close_on_read`.

Поведение первого аргумента (`<blob>`):
- `NULL` — создаётся новый пустой незакрытый BLOB.
- Постоянный BLOB (из таблицы) или закрытый временный BLOB — создаётся новый пустой незакрытый BLOB, куда копируется содержимое первого аргумента.
- Временный незакрытый BLOB — повторно используется без создания нового объекта.
- Другие типы данных — преобразуются в строку, для которой создаётся новый временный незакрытый BLOB.

Поведение последующих аргументов (`<value>`):
- `NULL` — игнорируется.
- Значения не-BLOB типов — преобразуются в строки и добавляются к результату.
- Значения типа BLOB — при необходимости транслитерируются к кодировке первого аргумента и дописываются к результату.

Движок автоматически закрывает сформированный BLOB при чтении его содержимого клиентом, записи в таблицу или использовании в операциях сравнения/конкатенации. Проверка на `IS [NOT] NULL` не читает данные и не приводит к закрытию BLOB.

## Пример
```sql
EXECUTE BLOCK
RETURNS (B BLOB SUB_TYPE TEXT)
AS
BEGIN
  -- Создаёт новый временный незакрытый BLOB и записывает строку
  B = BLOB_APPEND(NULL, 'Hello ');

  -- Добавляет во временный BLOB две строки, не закрывая его
  B = BLOB_APPEND(B, 'World', '!');

  -- Сравнение требует чтения данных, поэтому закроет BLOB
  IF (B = 'Hello World!') THEN
  BEGIN
    -- ...
  END

  -- Оператор || создаст уже закрытый временный BLOB
  B = B || 'Close';

  SUSPEND;
END
```
