# ANY VALUE

## Доступно в
DSQL

## Формат
```sql
ANY_VALUE(<expression>)
```

## Описание
Агрегатная функция `ANY_VALUE` возвращает некоторое значение переданного выражения `<expression>` для группы строк. Функция является недетерминированной. Тип возвращаемого результата совпадает с типом аргумента. В качестве выражения могут выступать столбцы таблиц, литералы, переменные, выражения, неагрегатные функции или UDF.

Значения `NULL` игнорируются при вычислении. Результат `NULL` возвращается только в том случае, если в группе отсутствуют записи со значениями выражения, отличными от `NULL`.

Функция предназначена для упрощения и оптимизации агрегатных запросов. Она позволяет избежать включения в секцию `GROUP BY` избыточных столбцов, которые функционально зависят от ключевого поля (например, атрибутов сущности при группировке по её первичному ключу). Использование `ANY_VALUE` эффективнее традиционных обходных решений с `MIN` или `MAX`, поскольку не требует сравнения значений внутри группы и возвращает первое попавшееся значение с минимальными затратами вычислительных ресурсов.

Функция добавлена в Firebird 6.0 (версия находится в разработке, доступна в снапшотах).

## Пример
```sql
SELECT
  EMPLOYEE.EMP_NO,
  ANY_VALUE(EMPLOYEE.FIRST_NAME) AS FIRST_NAME,
  ANY_VALUE(EMPLOYEE.LAST_NAME) AS LAST_NAME,
  SUM(SALES.TOTAL_VALUE) AS TOTAL_SUM,
  COUNT(*) AS CNT
FROM
  SALES
  JOIN EMPLOYEE ON EMPLOYEE.EMP_NO = SALES.SALES_REP
GROUP BY 1;
```
