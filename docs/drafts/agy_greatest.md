# GREATEST

## Доступно в
DSQL, PSQL

## Формат
```sql
GREATEST( <value> [, <value> ...] )

MAXVALUE ( <value> [, <value> ...] )
```

## Описание
Функция `GREATEST` возвращает максимальное значение из переданного списка выражений (чисел, строк или параметров с типом `DATE`, `TIME`, `TIMESTAMP`). В качестве аргументов допускаются выражения любого совместимого типа. Тип возвращаемого результата совпадает с типом первого аргумента функции.

Функции `GREATEST` и `MAXVALUE` являются синонимами. `GREATEST` представляет собой совместимый с SQL-стандартом псевдоним функции `MAXVALUE`, которая использовалась в предыдущих версиях Firebird.

Если один или более входных параметров имеют значение `NULL`, результатом работы `GREATEST` также будет `NULL`. В этом заключается ключевое отличие скалярной функции `GREATEST` от агрегатной функции `MAX`, которая игнорирует неопределённые значения при вычислениях.

Функция `GREATEST` является новой в Firebird 6.0 (версия находится в разработке и доступна в виде снапшотов).

## Пример
Использование функции `GREATEST`:
```sql
SELECT GREATEST(PRICE_1, PRICE_2, 10) AS PRICE
FROM PRICELIST
```

Использование синонима `MAXVALUE`:
```sql
SELECT MAXVALUE(PRICE_1, PRICE_2) AS PRICE
FROM PRICELIST
```
