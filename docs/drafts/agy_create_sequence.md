# CREATE SEQUENCE

## Доступно в
DSQL, ESQL

## Формат
```sql
CREATE {SEQUENCE | GENERATOR} seq_name
[START WITH start_value] [INCREMENT [BY] increment]
```

## Описание
Оператор `CREATE SEQUENCE` предназначен для создания новой последовательности (генератора) в базе данных. Ключевые слова `SEQUENCE` и `GENERATOR` являются полными синонимами, однако для соответствия стандарту SQL рекомендуется использовать `SEQUENCE`. Имя последовательности `seq_name` может содержать до 63 символов.

Необязательное предложение `START WITH` задаёт начальное значение последовательности (по умолчанию `1`). Необязательное предложение `INCREMENT [BY]` определяет шаг приращения в виде 4-байтового целого числа (по умолчанию `1`). Для пользовательских последовательностей шаг приращения не может быть установлен в ноль.

В момент создания последовательности ей устанавливается значение, равное значению из предложения `START WITH` минус значение приращения из предложения `INCREMENT [BY]`. Если предложение `START WITH` опущено, по умолчанию используется `1`. Благодаря этому первое значение, полученное с помощью оператора `NEXT VALUE FOR`, будет в точности равно значению `start_value` (до версии Firebird 4.0 первое значение вычислялось как `start_value + increment`). Например, если начальное значение равно 100, а шаг 10, первое значение `NEXT VALUE FOR` будет равно 100.

Шаг приращения, заданный в `INCREMENT [BY]`, применяется по умолчанию оператором `NEXT VALUE FOR`. При этом значение последовательности также можно изменять с помощью функции `GEN_ID`, где шаг приращения передаётся отдельным параметром и может отличаться от указанного при создании.

## Пример
```sql
-- Создание последовательности с начальным значением 100 и шагом приращения 10
CREATE SEQUENCE seq_customer_id
  START WITH 100
  INCREMENT BY 10;
```
