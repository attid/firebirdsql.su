# SAVEPOINT

## Доступно в
DSQL

## Формат
```sql
SAVEPOINT sp_name
```

## Описание
Оператор `SAVEPOINT` предназначен для создания SQL:99-совместимой точки сохранения в контексте текущей транзакции. Точки сохранения (также известные под термином «вложенные транзакции» / *nested transactions*) позволяют при необходимости откатывать внесённые изменения к определённому состоянию, не отменяя при этом всю работу, выполненную с момента старта транзакции.

Параметры оператора:
* `sp_name` — имя точки сохранения, которое должно быть уникальным в рамках транзакции. Если точка сохранения с указанным именем уже существует в текущей транзакции, старая точка удаляется и создаётся новая с тем же именем.

Для отката изменений к созданной точке сохранения используется оператор `ROLLBACK TO SAVEPOINT`.

Внутренний механизм точек сохранения может потреблять значительные объёмы памяти, особенно при многократном обновлении одних и тех же записей внутри одной транзакции. Если точка сохранения больше не требуется, но завершать саму транзакцию ещё не планируется, её можно удалить с помощью оператора `RELEASE SAVEPOINT`, освободив выделенные ресурсы.

## Пример
```sql
CREATE TABLE TEST (ID INTEGER);
COMMIT;

INSERT INTO TEST VALUES (1);
COMMIT;

INSERT INTO TEST VALUES (2);
SAVEPOINT Y;
DELETE FROM TEST;
SELECT * FROM TEST; -- возвращает пустую строку

ROLLBACK TO Y;
SELECT * FROM TEST; -- возвращает две строки

ROLLBACK;
SELECT * FROM TEST; -- возвращает одну строку
```
