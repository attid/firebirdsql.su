• # Что такое Firebird

  **Firebird** — свободная реляционная система управления базами данных (СУБД). Это программа, которая хранит данные приложений: справочники, документы, остатки на складах, результаты измерений. Исходный код открыт, пользоваться можно бесплатно — в том числе в коммерческих продуктах.

  Проект вырос из СУБД **InterBase 6.0** компании Borland: в июле 2000 года её исходники были опубликованы под открытой лицензией, и сообщество продолжило разработку уже как Firebird. Поэтому старые программы под InterBase часто совместимы с Firebird почти напрямую.

  ## Ключевые факты

  | Факт | Значение |
  |---|---|
  | Лицензия | IDPL (на основе MPL) — полностью бесплатно, включая коммерческое использование |
  | Файл базы | Один файл `.fdb` (или `.gdb` у совсем старых баз) |
  | Сетевой порт | 3050/TCP |
  | Язык сервера | PSQL: хранимые процедуры, триггеры, генераторы |
  | Платформы | Windows, Linux, macOS (и ряд других Unix) |
  | Режимы работы | Классический сервер, SuperServer и embedded — встроенный, без установки сервера |

  Если вы нашли на компьютере процесс **fbserver.exe** (или fb_inet_server.exe) и файл с расширением `.fdb` — это почти наверняка Firebird: какая-то программа на вашем компьютере хранит в нём свои данные. Удалять процесс и файл не стоит — вместе с ними пропадут данные этой программы.

  ## Версии: что актуально

  - **Firebird 5.0** — актуальная ветка, рекомендуется для новых проектов.
  - **Firebird 4.0** — большой релиз: оконные функции, полноценный тип `BOOLEAN`, встроенная репликация, увеличенный лимит на длину идентификаторов.
  - **Firebird 3.0** — переработанная архитектура, многопоточность; до сих пор часто встречается в установках.
  - **Firebird 2.5** — официально устарел, но жив: огромное количество учётных систем, установленных 10–15 лет назад, работает на нём до сих пор.

  ## Где встречается Firebird

  Firebird редко покупают «как СУБД» — чаще он приходит в составе другого софта:

  - **Учётные и бухгалтерские системы.** Масса российского и европейского отраслевого ПО (склад, производство, ЖКХ, медицина, АЗС, кассы) использует Firebird как встроенное хранилище.
  - **Десктопное отраслевое ПО.** Программа устанавливается вместе с сервером Firebird или embedded-библиотекой — пользователь может вообще не знать, что у него есть СУБД.
  - **Встраивание в приложения.** Embedded-режим позволяет приложению работать с базой через библиотеку, без отдельного сервера, — удобно для однопользовательских программ.

  ## Честное сравнение с MySQL и PostgreSQL

  | | Firebird | MySQL | PostgreSQL |
  |---|---|---|---|
  | Цена | Полностью бесплатен, редакций нет | Бесплатен, но часть функций в Enterprise | Полностью бесплатен |
  | Модель хранения | Один файл на базу — легко копировать и переносить | Каталог данных, перенос сложнее | Каталог данных, перенос сложнее |
  | Встраивание | Embedded из коробки | Ограниченно | Нет |
  | Экосистема | Скромная: меньше инструментов, хостингов, разработчиков | Огромная | Огромная |

  Сильные стороны Firebird — отсутствие платных редакций и ограничений, простое развёртывание (сервер ставится за минуту и не требует администратора), компактность и встраиваемость. Слабые — узкое сообщество: найти разработчика, хостинг или готовый ответ на нестандартный вопрос заметно труднее, чем для MySQL или PostgreSQL. Если вы выбираете СУБД для нового крупного проекта «с нуля», это стоит учесть. Если Firebird уже работает внутри вашей учётной системы — он надёжен, и спешить менять его обычно не нужно.
