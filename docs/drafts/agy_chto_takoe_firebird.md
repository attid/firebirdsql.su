# Что такое Firebird: разбираемся с программой и файлами .fdb

Если вы обнаружили в диспетчере задач процессы `fbserver.exe`, `firebird.exe` или `fb_inet_server`, а на диске — увесистые файлы с расширением `.fdb` (или `.gdb`), значит, на вашем компьютере или сервере установлена **СУБД Firebird**.

**Firebird** — это свободная компактная реляционная система управления базами данных (СУБД). Проект зародился в 2000 году, когда компания Borland открыла исходный код своей коммерческой СУБД InterBase 6.0. С тех пор сообщество полностью переписало и развило движок в самостоятельный современный продукт.

---

## Ключевые факты о Firebird

| Параметр | Значение |
| :--- | :--- |
| **Тип** | Реляционная СУБД (RDBMS) с поддержкой ACID и транзакций |
| **Лицензия** | IDPL / IPL (открытый исходный код, полностью бесплатна, включая коммерческое использование) |
| **Хранилище** | Вся база данных хранится в одном файле `.fdb` (структура, данные, триггеры, процедуры) |
| **Сетевой порт** | `3050/TCP` (стандартный порт сервера) |
| **Процедурный язык** | PSQL (поддержка хранимых процедур, триггеров, исключений и автономных транзакций) |
| **Платформы** | Windows, Linux, macOS, FreeBSD (x86_64, ARM) |
| **Встраиваемость** | Режим **Embedded** — работа через DLL/so напрямую с файлом БД, без запуска отдельной службы |

---

## Где чаще всего встречается Firebird?

Firebird редко выбирают для модных веб-стартапов, но она чрезвычайно популярна в корпоративном и инженерном секторе:

1. **Бухгалтерские и складские программы:** множество учетных систем стран СНГ и Европы (например, отраслевые учетные платформы, торговые и кассовые программы) используют Firebird в качестве ядра.
2. **Отраслевое десктопное ПО:** медицинские информационные системы, базы данных для строительного проектирования, системы контроля доступа (СКУД), логистические комплексы.
3. **Встраиваемые решения:** благодаря версии Embedded разработчики упаковывают Firebird прямо в дистрибутив своей программы. Пользователь даже не подозревает, что под капотом работает полноценный SQL-сервер.

## Актуальные версии

* **Firebird 5.0 (Текущая стабильная):** параллельное выполнение запросов и профилирование, многопоточный бэкап, ускоренная компиляция PSQL.
* **Firebird 4.0:** поддержка типов `BOOLEAN`, `DECFLOAT`, встроенные оконные функции, поддержка часовых поясов, репликация из коробки.
* **Firebird 3.0:** переход на единый движок архитектур, поддержка криптографии, объектно-ориентированный C++ API.
* **Firebird 2.5 (Legacy):** официально устаревшая ветка, но до сих пор массово работает на сотнях тысяч рабочих мест из-за консервативности корпоративного софта.

## Честное сравнение: Firebird против PostgreSQL и MySQL

| Критерий | Firebird | PostgreSQL | MySQL / MariaDB |
| :--- | :--- | :--- | :--- |
| **Установка и администрирование** | Минималистично: поставил и забыл (Zero-admin) | Требует тонкого тюнинга и профильного DBA | Средняя сложность настройки |
| **Модель хранения** | Один файл `.fdb` (легко копировать и бэкапить) | Набор каталогов и табличных пространств | Каталоги с таблицами или общие tablespace |
| **Встраиваемый режим** | Полноценный Embedded (в один клик) | Нет штатного встраивания | Встраивание сложное и редко применяется |
| **Экосистема и сообщество** | Узкое сообщество, меньше готовых ORM/GUI-утилит | Огромная экосистема, стандарт индустрии | Огромная экосистема, лидер веб-разработки |
| **Лицензирование** | Бесплатна без деления на Enterprise/Community | Полностью бесплатна (PostgreSQL License) | Двойная лицензия (GPL / Commercial) |

**Главные плюсы Firebird:** феноменальная надежность при нулевом администрировании, переносимость базы одним файлом, полное соответствие стандартам SQL и честная бесплатность.  
**Главные минусы:** скромный выбор современных драйверов под новые языки, меньший объем документации и практически полное отсутствие специалистов на рынке труда по сравнению с PostgreSQL.
