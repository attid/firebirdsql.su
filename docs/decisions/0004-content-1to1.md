# ADR-0004: Контент первого этапа — 1:1, апгрейд потом

Статус: принято (владелец выбрал из сравнения вариантов).

## Контекст

Страницы уже в поисковой выдаче. Любое изменение содержимого при переносе —
риск расхождения с ожиданием поисковика и лишняя ручная работа на критическом
пути запуска.

## Решение

Первый проход миграции — чисто механическая конвертация: та же структура
разделов, то же содержимое, без правок фактов и опечаток (кроме случаев, когда
страница физически не существует — она не переносится, а попадает в карту
редиректов на релевантный раздел). Доработки контента (Firebird 5.x, примеры,
бейджи версий, гигиена) — отдельными итерациями после запуска и стабилизации.

## Последствия

- Конвертер не требует редакторских решений — его можно полностью автоматизировать
  и повторяемо перезапускать.
- Сравнение «до/после» тривиально: дамп legacy/ ↔ собранные страницы.
- Апгрейд контента — независимый конвейер, не блокирующий запуск.
