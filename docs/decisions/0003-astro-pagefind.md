# ADR-0003: Astro + Pagefind

Статус: принято (владелец выбрал из сравнения вариантов).

## Контекст

~215 страниц глоссария/FAQ, контент в Markdown после конвертации. Нужны:
типизированный контент, локальный поиск без внешних сервисов, тёмная тема,
минимум JS, подсветка SQL.

## Решение

Astro (content collections для глоссария) + Pagefind (статический индекс поиска,
строится после сборки). Тема — минимальный кастомный шаблон, без тяжёлых
UI-библиотек.

## Альтернативы

- **Eleventy**: проще и легче, но компонентность и экосистема слабее — всё
  строить руками.
- **Docusaurus**: поиск/версионирование из коробки, но React-тяжесть и
  узнаваемый дефолтный вид.

## Последствия

- Контент остаётся в Markdown; смена генератора в будущем — механическая.
- Pagefind работает по статическому индексу: сервер не участвует, внешний
  хостинг поиска не нужен.
- Сборка добавляет шаг индексации Pagefind после `astro build`.
